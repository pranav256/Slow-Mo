# Slow-Mo Video Player

A custom video playback utility built with Python and OpenCV allowing frame-by-frame pacing, playback speed adjustments, and slow-motion inspection.

## Features

- **Variable Playback Speed:** Dynamically throttle frame pacing to inspect high-speed footage in slow motion.
- **Frame-by-Frame Stepping:** Pause and step through frames sequentially with keyboard shortcuts.
- **Video Export:** Save slowed segments directly to disk.

## Tech Stack

- Python 3.8+
- OpenCV (`opencv-python`)
- NumPy

## Run

```bash
pip install -r requirements.txt
python main.py
```
